# Review: every question and the game (Oct 26 2026)

Pankaj asked for a thorough review of all questions and the game, planned with the Consensus Board, then a fix pass. This file records how it was done, what was found and what is left.

## Method (board-reviewed: claude, codex, reasonix, opencode; chair confidence 72)
- **Blind answering.** Seven content reviewers answered every item in their slice from a copy with no keys, hints or explanations before opening the keyed file. A disagreement forced a re-check against current docs.
- **Planted defects.** Each slice hid 6 altered copies of real items (2 wrong keys, 2 hints that quote the key, 1 item with two right answers, 1 wrong task statement). Reviewers caught **42 of 42**. The copies were never written to the bank.
- **Risk-weighted slices.** Whole task statements per reviewer; the 197 older items with no source and the drift-prone task statements (1.3, 2.3, 2.5, 4.3) counted extra.
- **Independent verification.** A verifier re-checked every serious finding (docs first, reviewer's argument second) and blind-answered a random 5% of items marked clean: **0 wrong keys in 37**. A second pair of verifiers blind-answered all 66 rewritten items: **66 of 66** matched their keys.
- **One apply pass.** Reviewers wrote JSON findings only; one script applied them in order (reviewers → verifier → rewrites → second verification → scenario retags).

## Severity rubric
| Level | Meaning |
|---|---|
| S0 | wrong key, two defensible answers, answer flips under current docs, copied text |
| S1 | hint gives the answer away, other exploitable cue, wrong task statement or scenario, explanation that is wrong or teaches current behaviour as wrong |
| S2 | weak explanation, missing source, near-duplicate, implausible distractor |
| S3 | polish |

## Question bank: what was found and fixed (466 of 745 items touched, ids unchanged)
- **Hints were the one real cue.** Matching hint words to options found the key 48% of the time (chance 25%), and 72 hints shared a 12+ character run with the key. ~200 hints rewritten; the same guess now finds the key 8%. New gate: `scripts/check_cues.py`.
- **Docs drift.** Items whose answer would flip under today's docs were reframed so they hold under both the guide and current docs: `allowedTools` / `allowed-tools` only pre-approve (f02-02, f05-02, f06-08, d3-030), forced and `"any"` tool_choice pinned to models that support them (10 items), prompt-position advice (f09-03, f09-11), skills reload behaviour (f05-08, mx1-07), commands and skills being one system (f05-14).
- **Keys.** f06-08's key changed; d4-035 had two defensible answers and was rewritten. Keys that stood out by length or by being the only nuanced option were rebalanced (key is longest: 23% → 21%).
- **Explanations** that were wrong (e.g. subagents can't message the coordinator; `$ARGUMENTS` is positional; a hard "~15 tools" threshold) were corrected.
- **Coverage.** 66 near-duplicates (same concept, same decision) were rewritten into topics the guide lists but no item tested, e.g. `pause_turn`, parallel sectioning and voting, evaluator-optimizer, PreToolUse `defer`, PostToolUseFailure, `updatedToolOutput`, isError vs protocol errors, `errorCategory` as an app convention, SSE deprecation, tool consolidation, path rules and nested CLAUDE.md after compaction, `/context`, `disallowed-tools`, Explore without CLAUDE.md, GitHub Action v1 inputs, `--bare`, structured-output limits (citations, prefill, unsupported keywords, refusal), batch retention and cancel, context rot, `/compact` focus, SessionStart `compact` hooks.
- **Revisions.** Items whose key or concept changed carry `rev: 1` (67 items). The game resets a player's saved stats for an item when its rev moves past the stored one, so readiness never counts a first try on an old version.
- **Sources.** Every item now has `src` (the 197 older items had none).
- **Scenarios.** 178 items carried a scenario that does not cover their domain (e.g. a D1 item labelled "Claude Code for CI", which covers D3/D4). They now carry a covering scenario that fits the stem, or 0 (general). `check_bank.py` enforces this. Mocks still fill exact 16/11/12/12/9 quotas from the four drawn scenarios.
- **Exam guide delta 1.4:** `defer` works only in `-p` runs with one tool call per turn.

## Game: what was found and fixed
Logic and saved state (14 findings), all fixed: a second tab could wipe the other's progress; a saved mock would silently mis-grade after a question's options changed (now fingerprinted per item, v1 records voided with a notice); old Clinic cards mapped to the wrong question; unanswered mock items flooded the Clinic; spread drills stopped serving unseen items first; Recall Sprint blocked first tries; UTC streaks; abandoned mocks didn't count exposure; corrupt saves broke every screen; plus smaller XP and trophy edge cases. Save schema 5.

Presentation and exam realism (25 findings), all fixed: keyboard users couldn't start most modes (cards are buttons now); the answer modal is a real dialog; the mock timer stays visible on phones; grid cells announce their state; contrast meets WCAG AA in light and dark; reduced motion is honoured; the theme follows the system; the strict mock no longer shows each item's domain and task statement; the score shows as a range, not one number; the single-answer limitation is stated on the home card, the mock intro and the result; stale copy removed. axe-core: 186 violations → 0 across 96 screen runs (24 screens × desktop/phone × light/dark).

## Learn PR (#3)
Reviewed report-only and handed to its thread, which is fixing all 15 findings there (the main ones: a lesson stating "allowedTools must include Task" without the drift caveat, 23 quick checks that restated bank items, a loop example that exited on any non-tool_use stop reason).

## Left on purpose
- Multiple-response items: still single-answer (the real exam has both). Disclosed in the UI; build them as their own change.
- Absolute words (always/never/only) appear in 37% of distractors vs 19% of keys. The measured guessing gain is about 2 points, so it is tracked, not gated.
- Hints now lean slightly away from the key (8% vs 25% chance). Avoiding the hint-matching option gains about 2 points on a quarter of items; tracked by `check_cues.py`.
- Domain 5 sits at the 18-per-task-statement floor on 5.1, 5.2 and 5.4.
- A few near-duplicate pairs remain (e.g. f04-13/f04-01, f07-08/d4-102).
- Two tabs act "last action wins": simultaneous actions in both tabs can still lose one.
